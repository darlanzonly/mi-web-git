
# Mi Primera Web en Git

Proyecto web básico desarrollado con HTML para aprender
el uso de Git y GitHub, el control de versiones,
el trabajo con ramas y los Pull Requests.

- [Instalación](#instalación)

## Instalación

1. Clonar el repositorio:

   ```bash
   git clone https://https://github.com/darlanzonly/mi-web-git
   ```

2. Entrar en la carpeta:

   ```bash
   cd mi-web-git
   ```

3. Abrir el archivo `index.html` en el navegador.

## Estructura del proyecto

- `index.html`: página web principal.
- `README.md`: documentación del proyecto.
- `.gitignore`: archivos y carpetas excluidos de Git.
- `.vscode/`: configuración local del editor, excluida del repositorio.
